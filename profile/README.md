# Roversa Robotics

**Roversa Robotics builds Roversa, an open-source robot and learning ecosystem that helps K–12 educators teach computer science, AI, and robotics.**

Roversa was born out of a research collaboration between the University of Virginia and Universidad del Norte (Colombia). This GitHub organization is where we share the robot's hardware designs, firmware, MakeCode extensions, games, and classroom projects so that anyone can build, teach with, and improve Roversa.

## 📖 Open Source Resource Guide

At Roversa, we believe innovation thrives when ideas are shared openly. The [Roversa Open Source Resource Guide](https://docs.google.com/document/d/1vIAqBYdwO96W8BEA5-UW37aS7YUrKFE5CEhJWC0LX5Q/edit?usp=sharing) invites educators, hardware designers, and software developers to collaborate on accessible, creative robotics education.

- **[Community Code of Conduct](https://roversa.circle.so/c/start-here/community-code-of-conduct)**: our shared values; please read before joining in.
- **[Roversa Community](https://roversa.circle.so/)**: share projects, ask questions, find collaborators, and get updates on open-source initiatives.
- **[Roversa Lesson Repository](https://sites.google.com/roversa.com/roversa-classroom/lessons/repository)**: explore, remix, or contribute classroom-tested robotics lessons.
- **[Roversa Maker Guide](https://docs.google.com/document/d/1NiVh8kZtc4A7yyBcDE4P3tW2M-QwmfqLj-FiwIbA1L0/edit?usp=sharing)**: materials, laser cutting and 3D printing specs, assembly, troubleshooting, and customization for building Roversa locally.
- **Software:** firmware and micro:bit extensions live here on GitHub (listed below). Issues and pull requests are welcome.

## 🛠️ Open-source hardware

<img src="https://raw.githubusercontent.com/Roversa-Robotics/.github/main/profile/assets/roversa-chassis-3dp.png" alt="3D-printable Roversa chassis in Fusion 360" align="right" width="260">

- [**roversa2**](https://github.com/Roversa-Robotics/roversa2): the main Roversa robot platform repo, with parts list and ready-to-flash hex files.
- [**robot-chassis-3dp**](https://github.com/Roversa-Robotics/robot-chassis-3dp): a 3D-printable Roversa chassis (Fusion 360, STL, STEP).
- [**charging-station-3dp**](https://github.com/Roversa-Robotics/charging-station-3dp): a modular 3D-printable charging station for a classroom set of robots.
- [**manufacturing**](https://github.com/Roversa-Robotics/manufacturing): laser-cut and 3D-printed parts files for building Roversa.
- [**roversa-quest**](https://github.com/Roversa-Robotics/roversa-quest): 3D-printable direction die and game pieces for the [Roversa Adventure Quest](https://www.roversa.com/adventure-quest.html) classroom game.
- [**roversa-accessories**](https://github.com/Roversa-Robotics/roversa-accessories): add-on accessories for the robot.

## 🧩 Programming Roversa

- **[pxt-roversa-2](https://github.com/Roversa-Robotics/pxt-roversa-2)**: the Roversa extension for Microsoft MakeCode for micro:bit, with blocks for the robot's buttons, driving, speed, and steering trim.
- **[roversa-firmware](https://github.com/Roversa-Robotics/roversa-firmware)**: C/C++ CODAL firmware for the micro:bit V2 inside Roversa.
- **[servoRoversa](https://github.com/Roversa-Robotics/servoRoversa)**: C++ library for driving Roversa's continuous servo motors.
- **[batteryRoversa](https://github.com/Roversa-Robotics/batteryRoversa)**: C++ library for reading Roversa's battery voltage.
- **[KTD2052DriverRoversa](https://github.com/Roversa-Robotics/KTD2052DriverRoversa)**: C++ driver for the KTD2052 I2C RGB LED module.
- **[microbit-v2-BirdBrain-BLE](https://github.com/Roversa-Robotics/microbit-v2-BirdBrain-BLE)**: BirdBrain Bluetooth firmware for micro:bit V2, plus forks of the BirdBlox/FinchBlox apps (under development).
